# Content and attribution

Parallax 2.0 is an independent fan recreation inspired by Strategema as shown
in *Star Trek: The Next Generation*, “Peak Performance.” It is not an official
Star Trek product and is not endorsed by the franchise's rights holders.

## Presentation reference

The upright transparent panes, nested rectilinear outlines, lavender and yellow
fields, ring markers, perforated tabletop projector, and fingertip cables were
developed with reference to publicly viewable episode stills:

- [Ex Astris Scientia — observations of “Peak Performance”](https://www.ex-astris-scientia.org/observations/peakperformance.htm)
- [Let's Watch Star Trek — reference still](https://www.letswatchstartrek.com/wp-content/uploads/2013/05/Picture-518.png)

Those episode images are reference material, not assets inside the application.
The UI names Strategema and acknowledges the Star Trek inspiration; it does
not claim to be an unrelated, neutral-identifier production design.

## Assets actually included

- Procedural SceneKit geometry and an originally drawn perforation texture.
- An original geometric application icon generated by `Scripts/generate-icon.swift`.
- Synthesized tones, drones, and action sounds generated by the audio engine.
- Eight authored training scenarios and an original, deterministic ruleset.
- Documentation and the compiled application.

There are no bundled episode stills, video clips, music recordings, actor
portraits, character voice recordings, downloaded texture packs, or filler
media. The game rules are a playable interpretation, not a claim that the
television production specified these mechanics.

## Software and release status

The native application uses Apple SDK frameworks including SwiftUI, AppKit,
SceneKit, Metal, and AVFoundation. The Swift package has no external package
dependencies. Legacy prototype files and experimental networking code are not
a hosted production service; no Vapor/PostgreSQL/Redis backend is bundled.

The local installer is ad-hoc signed for integrity checking. It has not been
Developer ID signed or notarized. `content-manifest.txt` records resource hashes;
it is an integrity inventory, not a software bill of materials or rights audit.

This document records provenance and project scope. It does not grant rights
to the Star Trek franchise or constitute clearance for public distribution.
